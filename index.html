04

ФУНКЦИОНАЛ SEVENWAVE

Основные возможности текущей версии, собранные по интерфейсу SevenWave V2.01.

AIM

LEGIT BOT

  • Legit Aim — наведение по выбранной кнопке с регулируемой плавностью.
  • Fire Check — дополнительная проверка перед активацией наведения.
  • Aim Bind — отдельная клавиша или кнопка мыши для работы функции.
  • Hitboxes — выбор точки наведения.
  • FOV — настройка угловой области поиска цели и отображение FOV.
  • TriggerBot — реакция при попадании выбранной области цели в прицел.
  • Trigger Delay — регулируемая задержка активации.
  • Crosshair Tolerance — настройка допуска относительно центра прицела.
AIM

RAGE BOT

  • Rage Aim — более быстрое наведение внутри настроенного FOV.
  • Hitbox Expander ДОСТУПНО — расширение области регистрации выбранного hitbox.
  • Fire Check — дополнительное условие активации.
  • Activation Mode — отдельный режим включения Rage Bot.
  • Aim Bind — назначение собственной кнопки.
  • Hitboxes + FOV — выбор зоны и радиуса работы.
  • TriggerBot — отдельные delay и crosshair tolerance для Rage.
  • Aim Lock — удержание доступной цели внутри заданного FOV.
ESP

PLAYERS

  • Boxes — рамки вокруг игроков.
  • Nickname — отображение никнейма.
  • HP Indicator — индикатор здоровья.
  • Ammo — отображение боезапаса.
  • Weapon ESP — информация об оружии игрока.
  • Head — отдельная отметка головы.
  • Skeleton — отображение скелета модели.
  • Enemies Only — показ только противников.
  • Display Distance — настройка дистанции отображения.
  • Player Distance — вывод расстояния до игрока.
ESP

ITEMS & GRENADES

  • Dropped Weapons — отображение оружия на земле.
  • Dropped Grenades — отображение выброшенных гранат.
  • Icon + Name — название и компактная иконка предмета.
  • Item Distance — расстояние до предметов.
  • Grenade Prediction — визуализация траектории гранаты.
  • HE / Molotov / Flash / Smoke / Thermite — отдельные типы гранат.
  • Landing Marker — предполагаемая точка приземления.
  • Timer — таймер гранаты.
  • Observed Bounce Points — отображение точек отскока.
VISUAL

CHAMS & APPEARANCE

  • Chams — настройка цвета, прозрачности и материала модели.
  • Materials — Matte / Solid, Outline, Glow, Glass, Neon, Flat, Wireframe, Pearl, Metal и другие.
  • Animated Materials — Animated Gradient и Animated Glow.
  • Live Preview — предпросмотр изменений прямо в меню.
  • Appearance — единая настройка внешнего вида ESP и Preview.
  • Rectangle / Corners — выбор формы рамки.
  • Color — отдельная настройка цвета.
  • Line Width — регулировка толщины линий.
WORLD

WORLD SETTINGS

  • Hands — отдельный раздел настроек рук.
  • Lighting — управление визуальными параметрами освещения.
  • Sky — отдельные настройки неба.
  • Weather — отдельный раздел погодных параметров.
  • World Brightness — регулировка яркости внешнего мира.
  • Model Light Color — настройка освещения моделей.
  • Sun Color — выбор цвета направленного света.
MISC

WEAPON & MOVEMENT

  • No Recoil — автоматическая компенсация отдачи.
  • Compensation — настройка силы компенсации.
  • Smoothing — отдельная настройка сглаживания.
  • No Spread — коррекция разброса при стрельбе.
  • BHop — управление перемещением в воздухе при прыжках.
  • Legit / Rage BHop — два режима поведения.
CFG

CONFIGS & GENERAL

  • Profiles — отдельные профили настроек.
  • Save / Load / Refresh — сохранение, загрузка и обновление профилей.
  • Save As — создание нового профиля из текущих настроек.
  • Auto-load — автоматическая загрузка выбранного профиля при запуске.
  • Autosave — автоматическое сохранение изменений.
  • Startup Profile — выбор стартового профиля.
  • Language — настройка языка интерфейса.
  • Menu Key — выбор клавиши открытия меню.
