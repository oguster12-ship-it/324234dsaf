## Функционал на странице
Собран по предоставленным скриншотам SevenWave V2.01:
Legit Bot, Rage Bot, Hitbox Expander, TriggerBot, Aim Lock, ESP, Items, Grenades,
Chams, Appearance, World, No Recoil, No Spread, BHop, Configs / General.

Silent Aim на сайте не используется — вместо него указан доступный Hitbox Expander.

## Публикация
Загрузить содержимое архива в корень `sevenwave-v2.github.io` с заменой:
- index.html
- styles.css
- script.js
- assets/

GitHub Pages должен смотреть на `main` → `/ (root)`.
